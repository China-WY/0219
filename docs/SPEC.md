# 纯函数驱动・可生长可繁衍的花朵系统 - 技术规范

## 1. 项目概述

- **项目名称**: 纯函数花朵系统 (Pure Function Flower System)
- **项目类型**: 交互式Web动画
- **核心功能**: 基于数学函数驱动的可生长、可繁衍的虚拟花朵系统
- **目标用户**: 数学/艺术爱好者、创意编程学习者

## 2. UI/UX 规范

### 2.1 布局结构

- **画布**: 全屏Canvas覆盖
- **信息面板**: 顶部居中，显示系统时间和花朵信息

### 2.2 视觉设计

#### 色彩方案
- **背景**: 深蓝渐变 `#0a0a1a` → `#1a1a3a`
- **花茎**: 绿色渐变 `#2d5a27` → `#4a7c43`
- **花瓣外**: 粉红 `#e8a4b8`
- **花瓣内**: 深粉 `#d4738f`
- **花蕊**: 金黄 `#f4c542` → `#e8a020`
- **叶片**: 绿色 `#3d6b35` → `#5a8f4f`

#### 字体
- **信息面板**: `Courier New`, 14px, 白色 70% 透明度

#### 花朵结构
- **花瓣**: 5-8瓣，椭圆形态
- **花蕊**: 放射状圆形
- **花茎**: 曲线茎干
- **叶片**: 2-4片，对称分布

### 2.3 动画效果

- **生长动画**: 平滑过渡，使用缓动函数
- **时间单位**: 1秒 = 60帧（requestAnimationFrame）
- **繁衍效果**: 新花从父花位置附近淡入

## 3. 功能规范

### 3.1 纯函数定义

#### 花朵生成函数
```
generateFlower(baseX, baseY, seed, timeS) → FlowerData
```

**输入参数**:
- `baseX`: 基础X坐标（父花位置）
- `baseY`: 基础Y坐标（父花位置）
- `seed`: 种子值（用于确定性计算）
- `timeS`: 当前生长时间（秒）

**输出**: 花朵完整形态描述对象

#### 生长曲线函数
```
growthCurve(t) = sin(t / 60 * π / 2)
```
- t < 60: 生长阶段，曲线从0到1
- t >= 60: 成熟阶段，保持最大值

#### 繁衍位置函数
```
newFlowerPosition(parentX, parentY, seed, generation) → {x, y}
```
- 使用确定性三角函数计算新位置
- 避免重叠，偏移角度基于seed

### 3.2 花朵结构（纯函数计算）

#### 花茎
- 长度: `80 + growth * 120` (80-200像素)
- 弯曲度: 基于 `sin(seed * 2)` 的确定性曲线

#### 叶片
- 数量: 基于seed的固定值 (2-4片)
- 大小: `20 + growth * 30` (20-50像素)
- 展开角度: `π/6 + growth * π/6`

#### 花瓣
- 数量: 5-8（基于seed确定）
- 长度: `30 + growth * 40` (30-70像素)
- 展开度: `growth * π/3` (从闭合到展开)
- 宽度: 基于seed的固定比例

#### 花蕊
- 半径: 8-15像素（基于seed）
- 颜色强度: 随成熟度增加

### 3.3 繁衍机制

- **触发条件**: 花朵生长时间 >= 60秒
- **繁衍间隔**: 60秒后每5秒繁衍一次
- **代数限制**: 最多5代（防止性能问题）
- **新花位置**: 基于父花位置，通过确定性偏移计算

### 3.4 时间系统

- **全局时间**: 从页面加载开始计数
- **花朵独立时间**: 每朵花有自己的生长计时器
- **显示**: 顶部显示系统运行时间和花朵计数

## 4. 纯函数约束

### 4.1 禁止使用
- ❌ `Math.random()`
- ❌ 全局变量
- ❌ 外部资源（图片、音频）
- ❌ 随机颜色/位置

### 4.2 允许使用
- ✅ 确定性数学函数（sin, cos, tan, pow, sqrt）
- ✅ 固定参数和seed
- ✅ Canvas 2D API

## 5. 验收标准

- [ ] 输入固定seed，生成的花朵形态一致
- [ ] 花朵随时间从0-60秒平滑生长
- [ ] 花朵在60秒时自动繁衍新花
- [ ] 新花从0秒开始生长，60秒后继续繁衍
- [ ] 整个系统无随机数、无状态、无外部依赖
- [ ] 相同参数产生完全相同的输出（可复现）

## 6. 技术实现

- **渲染**: Canvas 2D
- **动画**: requestAnimationFrame
- **时间**: performance.now() / 1000
- **无依赖**: 原生JavaScript，无外部库
